# Тестовые ключи подписи

Резервные копии тестовых ключей 240 и 241 (DESIGN.md §6.3). Их открытые части есть в
`include/flan/keys.hpp` только под `#ifdef _DEBUG`: Release-сборки этих ключей не знают
(`static_assert`), поэтому подписанное ими настоящим клиентом не принимается.

Парольная фраза обеих копий — открытая, это не секрет:

```
flan test keys 240-241
```

Рабочая копия под DPAPI привязана к машине и пользователю, поэтому её здесь нет. Сквозные
проверки создают её сами Debug-сборкой `flan-build` (она читает фразу из перенаправленного ввода):

```powershell
"flan test keys 240-241" | bin\x64\Debug\flan-build.exe key restore tests\keys\flan-key-240.flankey-backup --key <scratch>\key-240.flankey
```

Ключ указывается явно через `--key` и лежит вне репозитория: `flan-build` не пишет ключи внутрь рабочего дерева git.
